# Lovia — career portfolio v2

## Deploy to GitHub + Vercel
1. Create an empty public repository `lovia-portfolio` on Lovia’s GitHub account.
2. Upload the **contents of the `site/` folder** to the repository root (index.html, style.css, projects/, resumes/, vercel.json). Keep the directory structure intact. Do not upload the ZIP itself.
3. In Vercel: Add New > Project > Import `lovia-portfolio`. Framework preset **Other**, root directory `./`, no build command. Deploy.
4. Check home page, each of four project links, five PDF resume links, email and LinkedIn links on mobile and desktop.
5. After launch, add the real public URL to CVs and LinkedIn. Confirm contact information, current location, and skill proficiency before applications.

## What is verified vs pending

Projects are *simulated practice work*, not paid assignments. Sample records are fictional. No certifications are claimed. The location line in CVs must be updated after arrival. Legal work authorization for paid work from Oman must be confirmed independently.
